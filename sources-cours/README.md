# Sources des cours rédigés en HTML + KaTeX

Chaque dossier contient le fichier `cours.html` qui a servi à produire le PDF publié dans `public/cours/`.
Pour regénérer un PDF : placer à côté un dossier `katex/` (paquet npm `katex`, fichiers `dist/katex.min.css`,
`katex.min.js`, `contrib/auto-render.min.js`, `fonts/`), ouvrir `cours.html` dans Chromium et imprimer en PDF (A4, arrière-plans activés).
